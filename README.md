# 🍽️ Foodie-Fi SQL Case Study 


## 📌 Project Overview 

This project contains a complete SQL case study based on the **Foodie-Fi** dataset. The objective is to analyze customer subscriptions, plan upgrades, churn behavior, and business performance using **MySQL**. The project demonstrates SQL skills including data exploration, joins, aggregations, window functions, Common Table Expressions (CTEs), and business analytics.



## 📊 Dataset Information 

The Foodie-Fi database contains two main tables.

### **plans** 
| Column | Description | 
|---------|-------------| 
| `plan_id` | Unique plan identifier | 
| `plan_name` | Subscription plan | 
| `price` | Monthly/Annual price |

### **subscriptions** 
| Column | Description | 
|---------|-------------| 
| `customer_id` | Customer ID | 
| `plan_id` | Subscription plan | 
| `start_date` | Plan start date |
